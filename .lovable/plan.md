# Denser, Taller Comments Panels

## Changes
- Increase the shared comments feed height so more comments and replies remain visible at once on Collections, Deliveries, Sharpening, and Repairs.
- Make each comment bubble more compact by reducing its width, padding, text size, spacing, reply-preview size, and reaction controls.
- Keep the composer usable and preserve the current replies, mentions, reactions, live updates, and mobile scrolling.
- Use responsive heights so the larger feed fits both desktop popups and smaller phone screens without covering controls.

## Verification
